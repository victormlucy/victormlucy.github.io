PP434 · Data project

England’s council tax is still based on 1991 values

This project compares the council-tax bands homes were assigned using their 1991 values with what those homes are worth today.

In progress · Autumn 2026

The question

How do council-tax bands based on 1991 property values compare with the relative value of homes today?

The approach

The analysis will compare council-tax bands and bills across England with recent home values. The aim is to make the difference between the historic valuation basis and today’s housing market easier to examine.

Current status

This work is in progress. Charts, data sources and conclusions will be added as the analysis is completed; no findings are presented here yet.
